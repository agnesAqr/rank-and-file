# RankTests 작업 규칙

테스트는 통과시킬 대상이 아니라 규칙을 강제하는 검사기다. 루트와 `Source/AGENTS.md`를 먼저 읽는다.

## 테스트 목록

| ID | 테스트 | 통과 기준 |
|---|---|---|
| T1 | 골든 벡터: 참조 구현이 낸 대전 20건의 입력으로 C++ 전투를 돌린다 | 결과, 틱, 이벤트 수, 해시가 20/20 일치 |
| T2 | 결정성: 무작위 대전 1,000판을 두 번씩 돌린다 | 해시 1,000/1,000 일치 |
| T3 | 미러: 무작위 배치 1,000개를 자기 자신과 붙인다 | 1,000/1,000 무승부(Draw 또는 Timeout) |
| T4 | 배치 판정 등가성: 비트마스크 판정과 칸 단위 판정을 무작위 1만 건으로 비교 | 10,000/10,000 일치 |
| T5 | 검산 예제: 규칙 문서의 손계산 3건 | 손계산과 일치 |
| T6 | 승률 재현: 참조 구현과 같은 배치 1,000개로 밤 3·7·12 승률을 링크 켬·끔으로 계산 | 참조 구현의 값과 일치 |
| T7 | 특성 조각: 조각마다 손계산 예제 2개 이상 | 전부 일치 |
| T8 | 콘텐츠: 채택본 JSON이 관문 1을 통과하고 DataTable 행 수와 같다 | 탈락 0, 행 수 일치 |
| T9 | 런 스모크: 탐색 봇이 시드 10개로 런을 끝까지 돈다. 같은 시드를 두 번 | 멈춤과 크래시 0, 같은 시드는 같은 결과 |
| T10 | 재생 일치: 재생이 끝난 화면 상태와 `FBattleResult` 비교 | 일치 |

- 이름은 `RankAndFile.Core.*`, `RankAndFile.Content.*`, `RankAndFile.Run.*`로 나눈다. `tools\run_tests.bat`이 `RankAndFile` 전체를 돌린다.
- `IMPLEMENT_SIMPLE_AUTOMATION_TEST`로 쓴다. T1~T6은 화면 없이 돈다.

## 금지

- 기대값(해시, 틱, 이벤트 수, 승률)을 고쳐서 통과시키지 않는다.
- 테스트를 끄거나, 건너뛰거나, 판 수를 줄이지 않는다(1,000 → 100, 20 → 19).
- 허용 오차를 넣지 않는다. 정수와 해시의 비교는 정확히 같아야 한다.
- 실패를 "알려진 실패"로 분류해 빼지 않는다.
- 픽스처(`Fixtures/golden_v1.json`, `Fixtures/formations_1000.json`)를 손으로 고치지 않는다. `node tools/export_golden.js`로만 만든다. C++ 출력으로 골든 벡터를 다시 만들지 않는다.
- 참조 구현의 난수기와 무작위 배치 함수를 C++로 옮기지 않는다. 픽스처를 읽는다. 그 함수들은 실수 연산을 써서 옮기는 순간 차이가 생길 수 있다.

## 픽스처

- 픽스처에는 병과 수치와 규칙 매개변수의 해시가 들어 있다. 테스트는 시작할 때 지금 데이터의 해시와 비교하고, 다르면 "픽스처가 오래됐다"는 메시지로 실패한다. 조용히 통과하거나 건너뛰지 않는다.
- 수치나 규칙이 바뀌면 픽스처와 `docs/design.md`의 골든 벡터 표를 함께 다시 만든다.

## 실패했을 때

- 그대로 보고한다: 테스트 이름, 처음 어긋난 항목(시드, 틱, 이벤트 번호), 기대값과 실제값.
- T1이 어긋나면 `Source/RankCore/AGENTS.md`의 "골든 벡터가 어긋났을 때" 절차를 따른다.
- 테스트가 틀렸다고 판단되면 고치지 않고 근거와 함께 알린다. 테스트를 고치는 일은 사람이 승인한다.

## 테스트를 더할 때

- 버그를 고치면 그 버그를 잡는 테스트를 함께 넣는다. 고치기 전에 실패하고 고친 뒤에 통과하는 것을 확인한다.
- 참조 구현이 없는 부분(특성, 유물)은 손으로 계산한 예제를 기대값으로 쓴다. 구현을 돌려서 나온 값을 기대값으로 삼지 않는다.
- 무작위 입력을 쓰는 테스트는 시드를 고정하고 시드를 실패 메시지에 넣는다.

## 보고 형식

```
T1 20/20 · T2 1,000/1,000 · T3 1,000/1,000 · T4 10,000/10,000 · T5 3/3 · T6 일치
명령: tools\run_tests.bat · 빌드: Development Editor · 커밋: abc1234
```

실행된 테스트가 0개면 통과가 아니다. 테스트를 돌리지 못했으면 돌리지 못했다고 적는다.
