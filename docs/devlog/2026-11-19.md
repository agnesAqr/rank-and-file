## 버리거나 고친 것

- 빌드 명령: 첫 빌드가 Live Coding 때문에 막혀(종료 코드 6) UBT 옵션 `-NoHotReloadFromIDE`를 더했다(작업 세션 기록). 출처(11/20 일지 작성 때 UE 5.8.4 엔진 소스에서 확인): `Engine/Source/Programs/UnrealBuildTool/System/HotReload.cs` 270~278줄은 `BuildConfiguration.bAllowHotReloadFromIDE`가 참일 때만 Live Coding 세션을 검사하고 위 예외를 던진다. `Engine/Source/Programs/UnrealBuildTool/Configuration/BuildConfiguration.cs` 160~162줄의 `[CommandLine("-NoHotReloadFromIDE", Value = "false")]`가 이 값을 거짓으로 둔다. 같은 예외 문구는 에디터와 게임을 닫으라고 권하는데, 이번에는 에디터를 닫지 않고 옵션으로 검사를 건너뛰었다
- 에디터 종료 명령: `Quit`를 `QUIT_EDITOR`로 바꿨다. 이유: 5.8 에디터에서 `Quit`는 게임 쪽 명령이고, 에디터를 닫는 명령은 `QUIT_EDITOR`다(작업 세션 기록). 출처(11/20 일지 작성 때 확인): `Engine/Source/Runtime/Engine/Private/EngineService.cpp` 189~196줄은 `GEngine->IsEditor()`이면 `QUIT_EDITOR`를, 아니면 `QUIT`를 실행한다. `QUIT`·`EXIT`는 `UGameEngine::Exec`가 받고(`Engine/Source/Runtime/Engine/Private/GameEngine.cpp` 1530줄), `QUIT_EDITOR`는 `Engine/Source/Editor/UnrealEd/Private/EditorServer.cpp` 5993~5996줄에서 `CloseEditor()`를 부른다
- 남은 확인: `tools/AGENTS.md` 47줄은 `run_tests.bat`의 인자를 `-ExecCmds="Automation RunTests RankAndFile; Quit"`로 적고 있다. `run_tests.bat`을 만들 때 이 종료 명령이 실제로 에디터를 끝내는지 확인해야 한다. 아직 하지 않았다(작업 세션 기록). 참고(11/20 일지 작성 때 엔진 소스에서 확인): 이 `Quit`는 `Automation` 명령 안의 하위 명령이라 위의 `Quit`와 처리하는 곳이 다르다. `-ExecCmds`는 쉼표로만 명령을 나누고(`Engine/Source/Runtime/Engine/Private/ParseExecCommands.cpp` 28줄), `Automation` 명령은 세미콜론으로 하위 명령을 나눈 뒤(`Engine/Source/Developer/AutomationController/Private/AutomationCommandline.cpp` 582줄) `Quit`를 테스트 뒤의 종료로 줄 세운다(같은 파일 726~734줄, 491~504줄). 실제로 끝나는지는 첫 실행에서 본다 [미확인]
