## §1 용어

| 용어 | 뜻 |
|---|---|
| 진영 | 0이 플레이어(아군), 1이 해골 |
| 진형판 | 진영마다 6열 × 4행. 행 0이 적과 맞닿는 최전열 |
| 열 번호 | 0~5. 두 진영의 같은 열 번호가 서로 마주 본다 |
| 대열 | 전투 중 한 열에 남은 유닛의 줄. 앞에서부터 0, 1, 2…로 센다(대열 순번) |
| 틱 | 전투 시간의 단위. 1틱 = 0.1초 |
| 성문, 결계 | 진영 0의 내구도가 성문, 진영 1의 내구도가 결계다 |

## §2 기본 조항

**§2.1 진형판.** 내 진형은 6열 × 4행이고 0행이 적과 맞닿는 최전열이다. 분대는 1~4칸 폴리오미노(polyomino)이고 한 칸에 병사 한 명이 선다. 90도씩 돌릴 수 있고 겹칠 수 없다. 밤마다 모든 분대를 다시 놓을 수 있다.

**§2.2 링크.** 상하좌우로 맞닿은 두 병사의 병과가 다르면 링크가 하나 생기고, 두 병사는 서로 상대 병과의 보너스를 한 겹씩 받는다. 같은 병과끼리는 링크가 없다. 보너스는 종류마다 세 겹까지 쌓이고, 사거리는 최대 4, 공격 간격은 최소 4틱이다. 링크는 전투가 시작되는 순간의 배치로 확정된다.

**§2.3 대열.** 전투가 시작되면 열마다 병사들이 앞으로 붙어 한 줄 대열이 된다. 앞사람이 쓰러지면 뒷사람이 한 칸씩 전진한다. 빈칸은 링크 계산에만 쓰이고 전투에서는 사라진다.

**§2.4 행동.** 1틱은 0.1초다. 병사는 공격 간격마다 한 번 공격한다. 대열 앞에서 i번째(0부터 셈) 병사는 i가 사거리보다 작을 때만 공격하고, 아니면 공격 준비를 마친 채 기다린다.

**§2.5 표적.** 근접 병과는 마주 보는 열의 맨 앞을, 척후는 맨 뒤를 친다. 석궁수는 마주 보는 열의 맨 앞을 치고, 그 열이 비면 가장 가까운 열의 맨 앞을 친다(거리가 같으면 왼쪽). 마법사는 왼쪽·가운데·오른쪽 세 열의 맨 앞을 동시에 친다. 칠 대상이 없으면 상대 성문을 친다.

**§2.6 피해.** 물리 피해는 max(1, 공격 − 방어), 마법 피해는 방어를 무시하고, 성문 피해는 1이다. 한 틱의 모든 공격은 틱이 시작될 때의 상태로 표적을 정하고, 피해는 모은 뒤 한꺼번에 적용한다. 그래서 누가 먼저 처리되든 결과가 같다.

**§2.7 판정.** 내 병사가 전멸하거나 성문이 0이 되면 패배. 해골이 전멸하거나(섬멸) 결계가 0이 되거나(결계 파괴) 600틱을 버티면(새벽) 승리. 같은 틱에 양쪽이 함께 끝나면 성문이 남아 있을 때 승리다. 성문과 결계는 60에서 시작한다.

**§2.8 해골.** 해골에게는 링크가 없다. 해골 졸개는 처음 쓰러질 때 한 번 체력 6으로 다시 일어선다.

## §3 유닛 생성과 링크 계산

**§3.1 생성 순서.** 진영 0 → 1, 행 0 → 3, 열 0 → 5 순서로 칸을 훑어 유닛을 만든다. 유닛은 자기 열의 대열 뒤에 붙는다. 그래서 행 번호가 작은 유닛이 대열 앞에 선다.

**§3.2 유닛 번호.** 진영 × 100 + 행 × 6 + 열. 이 번호가 해시와 이벤트에 들어간다.

**§3.3 링크 보너스.** 칸의 상하좌우 이웃 가운데 병과가 다르고 그 병과에 링크 효과가 있는 이웃마다 그 효과를 한 겹 받는다. 해골은 링크 효과가 없으므로 링크를 주지도 받지도 않는다.

**§3.4 최종 능력치.**

| 능력치 | 식 |
|---|---|
| 방어 | 기본 + min(방어 링크, 3) |
| 공격 | 기본 + min(공격 링크, 3) |
| 사거리 | min(기본 + min(사거리 링크, 3), 4) |
| 최대 체력 | 기본 + 5 × min(체력 링크, 3). 시작 체력은 최대 체력 |
| 간격 | max(기본 − min(간격 링크, 3), 4) |

**§3.5 대기 시간.** 대기 시간(cd)의 처음 값은 간격이다. 그래서 첫 공격은 간격 번째 틱에 나간다.

## §4 한 틱의 처리 순서

틱은 1부터 최대 틱(600)까지 돈다.

**§4.1 단계.**

| 단계 | 처리 |
|---|---|
| ① 의도 수집 | 진영 0 → 1, 열 0 → 5, 대열 앞 → 뒤 순서로 유닛마다: cd가 0보다 크면 1 줄인다. cd가 아직 0보다 크거나 대열 순번이 사거리 이상이면 건너뛴다(cd는 0에 머문다. 준비된 채 대기). 아니면 §4.2로 표적을 고르고 cd를 간격으로 되돌린다 |
| ② 의도 없음 | 이번 틱에 의도가 하나도 없으면 ③~⑤를 건너뛴다 |
| ③ 적용 | 모은 순서대로 적용한다. 표적은 ①에서 고른 것을 바꾸지 않는다. 이미 체력이 0 이하가 된 표적에도 피해와 이벤트를 그대로 적용한다 |
| ④ 사망 정리 | 진영 0 → 1, 열 0 → 5, 대열 앞 → 뒤 순서. 체력이 0 이하이고 부활 값이 있으면 체력을 부활 값으로 바꾸고 부활 값을 0으로 한다(자리는 그대로). 부활 값이 없으면 대열에서 빼고 뒤의 유닛이 앞으로 당겨진다 |
| ⑤ 판정 | §5.1 |

**§4.2 표적.** "마주 보는 열"은 상대 진영의 같은 열 번호다. "왼쪽"은 열 번호가 작은 쪽이다.

| 표적 | 고르는 법 |
|---|---|
| 맨 앞 (방패병, 광전사, 해골 졸개, 해골 전사) | 마주 보는 열의 대열 맨 앞. 열이 비면 상대 성문 |
| 맨 뒤 (척후) | 마주 보는 열의 대열 맨 뒤. 열이 비면 상대 성문 |
| 지원 (석궁수, 해골 궁수) | 마주 보는 열의 맨 앞. 비면 거리 1부터 5까지, 같은 거리에서는 열 번호가 작은 쪽을 먼저 보고 처음 찾은 열의 맨 앞. 모두 비면 상대 성문 |
| 범위 (마법사, 해골 술사) | 열 번호 c−1, c, c+1 순서로, 진형판 안이고 비어 있지 않은 열의 맨 앞을 모두. 셋 다 비면 상대 성문을 한 번 |

**§4.3 피해.** 마법은 공격 값 그대로, 물리는 max(1, 공격 − 방어), 성문은 성문 피해 값이다. 범위 공격은 표적마다 따로 피해를 준다.

## §5 판정

**§5.1 코어 결과.** ④가 끝난 뒤, 한 진영의 성문(또는 결계)이 0 이하이거나 그 진영의 모든 열이 비었으면 그 진영이 진 것이다.

| 상황 | 결과 |
|---|---|
| 진영 1만 짐 | A |
| 진영 0만 짐 | B |
| 같은 틱에 둘 다 짐 | Draw |
| 최대 틱까지 끝나지 않음 | Timeout. 틱은 최대 틱으로 기록 |

**§5.2 플레이어 기준 판정.**

| 코어 결과 | 판정 |
|---|---|
| A | 승리. 결계가 0 이하면 결계 파괴, 아니면 섬멸 |
| Timeout | 승리, 새벽 |
| Draw | 성문이 남아 있으면 승리(성문 사수), 아니면 패배(성문 붕괴) |
| B | 패배. 성문이 0 이하면 성문 붕괴, 아니면 전멸 |

## §6 이벤트와 해시

해시는 FNV-1a 32비트다. 시작값 `0x811c9dc5`, 곱하는 수 `0x01000193`. 정수 하나를 섞을 때는 하위 바이트부터 4바이트를 차례로 XOR하고 곱한다. 곱셈은 32비트에서 넘침을 버린다.

| 이벤트 | 종류 값 | 생기는 때 | 해시에 섞는 순서 |
|---|---|---|---|
| 성문 타격 | 1 | ③에서 표적이 성문일 때 | 틱, 1, 공격자 번호, 999, 피해 |
| 피해 | 2 | ③에서 표적이 유닛일 때 | 틱, 2, 공격자 번호, 표적 번호, 피해 |
| 부활 | 3 | ④에서 부활할 때 | 틱, 3, 유닛 번호 |
| 사망 | 4 | ④에서 대열에서 뺄 때 | 틱, 4, 유닛 번호 |
| 종료 | | 전투가 끝날 때 한 번 | 마지막 틱, 결과 코드(A 1, B 2, Draw 3, Timeout 4) |

이벤트 로그의 항목도 같은 종류 값과 필드를 쓴다.

## §8 검산 예제

손계산 시나리오(T5)의 출발점이다. 기대값은 AI가 이 문서로 계산하고 사람이 확인한다(`Source/RankTests/AGENTS.md`).

1. 광전사와 맞닿은 방패병은 공격 3이다. 해골 전사(방어 1)에게 한 번에 2씩 들어가므로 체력 32를 깎는 데 16번, 간격 10틱이니 160번째 틱에 쓰러진다.
2. 석궁수 둘과 맞닿은 방패병은 사거리 3이다. 대열 셋째 자리(순번 2)에서도 공격한다.
3. 마법사와 맞닿은 척후는 체력 23이다(기본 18 + 5. 11/17 수치 조정 전에는 25). 척후 둘이 마법사 하나를 끼면 두 척후가 모두 +5를 받고, 마법사는 간격 −2틱(16 → 14)을 받는다.
