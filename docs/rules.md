## 한눈에 보기

플레이어는 병사 1~4명으로 된 분대(카드)를 자기 진형판에 놓는다. 놓고 나면 전투는 저절로 진행된다. 병사들은 열마다 한 줄로 서서, 마주 보는 해골의 열과 싸운다.

```
      열 번호   0   1   2   3   4   5
              ┌───┬───┬───┬───┬───┬───┐
 해골   행 3   │   │   │   │   │   │   │   ← 해골 쪽 맨 뒤
 진영   행 2   │   │   │   │   │   │   │
 (1)   행 1   │   │   │ r │ r │   │   │
       행 0   │ m │ w │ m │ m │ w │ m │   ← 해골 쪽 맨 앞
              ╞═══╪═══╪═══╪═══╪═══╪═══╡   ← 두 진영이 맞닿는 선
 플레이어 행 0  │ K │ K │ B │ B │   │ K │   ← 내 쪽 맨 앞
 진영   행 1   │ R │   │ R │ M │ H │   │
 (0)   행 2   │   │   │   │   │ H │   │
       행 3   │   │   │   │   │   │   │   ← 내 쪽 맨 뒤
              └───┴───┴───┴───┴───┴───┘
```

- 내 0열은 해골의 0열과, 내 5열은 해골의 5열과 마주 본다.
- 병사마다 정해진 박자로 공격한다. 체력이 0 이하가 되면 쓰러진다.
- 해골을 모두 쓰러뜨리거나, 해골 쪽 결계를 부수거나, 60초를 버티면 이긴다.

## §1 용어

| 용어 | 뜻 |
|---|---|
| 진영 | 편. 진영 0은 플레이어(아군), 진영 1은 해골이다 |
| 진형판 | 진영마다 하나씩 있는 6열 × 4행 칸. 행 0이 적과 맞닿는 맨 앞이다 |
| 열 번호 | 왼쪽부터 0~5. 두 진영에서 번호가 같은 열이 서로 마주 본다 |
| 병과 | 병사의 종류. 방패병, 광전사 같은 것. 병과마다 체력, 공격 같은 수치가 정해져 있다(§7) |
| 유닛 | 전투에 나선 병사 한 명 |
| 대열 | 전투 중 한 열에 남아 있는 병사들의 줄. 빈칸 없이 앞으로 붙어 선다. 맨 앞부터 0번째, 1번째, 2번째…로 센다(대열 순번) |
| 틱 | 전투 시간의 단위. 1틱 = 0.1초. 전투는 틱 단위로 한 칸씩 진행된다 |
| 간격 | 병사가 몇 틱마다 한 번 공격하는지. 간격 10이면 10틱(1초)마다 한 번 |
| 대기 시간 | 다음 공격까지 남은 틱. 간격에서 시작해 틱마다 1씩 줄고, 0이 되면 공격한다 |
| 사거리 | 대열에서 몇 번째 자리까지 공격할 수 있는지. 사거리 1이면 맨 앞에서만, 사거리 3이면 앞에서 세 번째 자리까지 공격한다 |
| 성문, 결계 | 각 진영의 내구도. 플레이어 쪽(진영 0)이 성문, 해골 쪽(진영 1)이 결계다. 둘 다 60에서 시작한다 |

## §2 기본 조항

**§2.1 진형판.** 내 진형판은 6열 × 4행이고, 행 0이 적과 맞닿는 맨 앞이다. 분대는 1~4칸이 변끼리 붙은 모양(폴리오미노, polyomino)이고, 한 칸에 병사 한 명이 선다. 분대는 90도씩 돌릴 수 있고, 다른 분대와 겹쳐 놓을 수 없다. 뒤집기(좌우 반전)는 없다. 그래서 L 모양과 J 모양처럼 서로 거울에 비친 모양인 분대는 다른 분대다. 밤(한 판)마다 모든 분대를 다시 놓을 수 있다.

**§2.2 링크.** 위·아래·왼쪽·오른쪽으로 맞닿은 두 병사의 병과가 다르면 둘 사이에 링크가 하나 생긴다. 링크로 이어진 두 병사는 서로 상대 병과가 주는 보너스를 한 겹씩 받는다. 같은 병과끼리는 링크가 없다. 대각선은 맞닿은 것이 아니다.
- 보너스는 종류마다 세 겹까지만 쌓인다(겹 상한). 같은 종류를 두 병과 이상이 주면 병과마다 따로 세 겹까지 쌓인다(§3.4).
- 사거리는 아무리 올라도 4까지(사거리 상한), 간격은 아무리 줄어도 4틱까지다(간격 하한).
- 위 세 값과 한 겹의 크기는 모두 §7의 매개변수이고, 값은 `Data/defs/`에서 온다.
- 링크는 병과로 정한다. 병사가 어느 진영에 서 있는지와 상관없다.
- 링크는 전투가 시작되는 순간의 배치로 정해진다. 전투 중에 옆 병사가 쓰러져도 받은 보너스는 그대로다.

예: 방패병(방어 +1을 줌)과 광전사(공격 +1을 줌)가 옆에 붙어 있으면, 방패병은 공격 +1, 광전사는 방어 +1을 받는다.

**§2.3 대열.** 전투가 시작되면 열마다 빈칸이 사라지고 병사들이 앞으로 붙어 한 줄(대열)이 된다. 앞사람이 쓰러지면 뒷사람들이 한 칸씩 앞으로 나온다. 앞으로 나와도 대기 시간(§3.5)은 그대로다. 그래서 공격 준비를 마친 채 기다리던 병사는 맨 앞으로 나온 다음 틱에 바로 친다. 빈칸은 링크를 계산할 때만 의미가 있고, 전투에서는 없는 것으로 친다.

예: 한 열의 행 0이 빈칸이고 행 1에 석궁수, 행 3에 마법사가 있으면, 전투에서는 석궁수가 대열 0번째, 마법사가 1번째다.

**§2.4 행동.** 1틱은 0.1초다. 병사는 간격마다 한 번 공격한다. 대열 앞에서 i번째(0부터 셈) 병사는 i가 사거리보다 작을 때만 공격한다. 아니면 공격 준비를 마친 채 기다린다.

예: 사거리 1인 광전사는 대열 0번째(맨 앞)에서만 친다. 1번째에 서 있으면 준비만 한 채 기다리다가, 앞사람이 쓰러져 맨 앞으로 나오면 친다.

**§2.5 표적.** 누구를 치는지는 병과마다 다르다.
- 근접 병과(방패병, 광전사, 해골 졸개, 해골 전사)는 마주 보는 열의 맨 앞을 친다.
- 척후는 마주 보는 열의 맨 뒤를 친다.
- 석궁수(와 해골 궁수)는 마주 보는 열의 맨 앞을 친다. 그 열이 비었으면 가장 가까운 열의 맨 앞을 친다. 거리가 같은 열이 둘이면 왼쪽(열 번호가 작은 쪽)을 친다.
- 마법사(와 해골 술사)는 왼쪽·가운데·오른쪽 세 열의 맨 앞을 동시에 친다.
- 칠 대상이 없으면 상대 성문(해골 쪽이면 결계)을 친다.

**§2.6 피해.**
- 물리 공격의 피해는 공격 − 방어다. 단, 최소 1이다. 식으로 max(1, 공격 − 방어).
- 마법 공격(마법사, 해골 술사)은 방어를 무시하고 공격 값 그대로 들어간다.
- 성문과 결계에 들어가는 피해는 공격과 상관없이 1이다.
- 한 틱 안의 모든 공격은 그 틱이 시작될 때의 상태를 보고 표적을 정한다. 피해는 모았다가 한꺼번에 준다. 그래서 누구를 먼저 처리하든 결과가 같고, 두 병사가 같은 틱에 서로를 쓰러뜨릴 수도 있다.

**§2.7 판정.**
- 패배: 내 병사가 모두 쓰러지거나, 성문이 0 이하가 된다.
- 승리: 해골이 모두 쓰러지거나(섬멸), 결계가 0 이하가 되거나(결계 파괴), 600틱(60초)을 버틴다(새벽).
- 같은 틱에 양쪽이 함께 끝나면, 성문이 남아 있을 때 승리다.
- 성문과 결계는 60에서 시작한다.

**§2.8 해골.** 해골에게는 링크가 없다. 해골끼리 붙어 있어도 보너스를 주고받지 않는다. 해골 졸개는 처음 쓰러질 때 한 번만 체력 6으로 다시 일어선다.

## §3 유닛 생성과 링크 계산

전투를 시작할 때 진형판의 칸을 읽어 유닛을 만드는 방법이다.

**§3.1 생성 순서.** 칸을 아래 순서로 훑으며 병사가 있는 칸마다 유닛을 만든다: 진영 0 → 1, 그 안에서 행 0 → 3, 그 안에서 열 0 → 5. 만든 유닛은 자기 열의 대열 맨 뒤에 붙는다. 그래서 행 번호가 작은(앞쪽) 병사가 대열 앞에 선다.

**§3.2 유닛 번호.** 유닛마다 번호를 붙인다: 진영 × 100 + 행 × 6 + 열. 예를 들어 플레이어 쪽 행 1, 열 2의 병사는 0 × 100 + 1 × 6 + 2 = 8번, 해골 쪽 행 0, 열 3의 해골은 1 × 100 + 0 + 3 = 103번이다. 이 번호가 해시(§6)와 이벤트 기록에 들어간다. 병사가 대열에서 앞으로 나와도 번호는 바뀌지 않는다.

**§3.3 링크 보너스.** 한 칸의 위·아래·왼쪽·오른쪽 이웃을 본다. 이웃의 병과가 나와 다르고, 그 병과에 링크 효과가 있으면(§7의 "링크로 주는 것"), 그 이웃 한 명마다 그 효과를 한 겹 받는다. 해골은 링크 효과가 없으므로 링크를 주지도 받지도 않는다.

링크는 병과만 보고 정한다. 진영은 보지 않는다. 그래서 진영 1에 아군 병과가 서 있으면(미러 테스트 T3처럼 같은 배치를 양쪽에 놓을 때) 그 병사들도 진영 0과 똑같이 링크를 주고받는다.

예: 석궁수(사거리 +1을 줌) 둘과 맞닿은 방패병은 사거리 보너스를 두 겹 받는다.

**§3.4 최종 능력치.** 링크 보너스를 더한 전투용 수치다. 식에서 n은 그 종류를 주는 병과에게서 받은 겹 수, a는 그 병과의 한 겹 크기(§7의 "링크로 주는 것")다. 겹 상한, 사거리 상한, 간격 하한도 §7의 매개변수다.

| 능력치 | 식 | 지금 값으로 |
|---|---|---|
| 방어 | 기본 + a × min(n, 겹 상한) | 방패병이 주는 a = 1. 최대 +3 |
| 공격 | 기본 + a × min(n, 겹 상한) | 광전사가 주는 a = 1. 최대 +3 |
| 사거리 | min(기본 + a × min(n, 겹 상한), 사거리 상한) | 석궁수가 주는 a = 1. 결과는 4를 넘지 않는다 |
| 최대 체력 | 기본 + a × min(n, 겹 상한) | 마법사가 주는 a = 5. 전투는 최대 체력으로 시작한다 |
| 간격 | max(기본 + a × min(n, 겹 상한), 간격 하한) | 척후가 주는 a = −1. 결과는 4틱보다 작아지지 않는다 |

같은 종류를 두 병과 이상이 주면 겹을 병과마다 따로 센다. 병과마다 a × min(n, 겹 상한)을 구해 모두 더하고, 사거리 상한과 간격 하한은 더한 뒤에 한 번 적용한다. 예: 공격 +1을 주는 병과 X가 이웃에 셋, 공격 +2를 주는 병과 Y가 이웃에 하나면 공격 보너스는 1 × min(3, 3) + 2 × min(1, 3) = +5다. 지금 데이터는 종류마다 주는 병과가 하나뿐이다.

**§3.5 대기 시간.** 대기 시간의 처음 값은 간격이다. 그래서 첫 공격은 간격 번째 틱에 나간다. 예: 간격 10인 방패병은 10, 20, 30번째 틱에 친다.

**§3.6 시작 조건.** 양쪽 진영에 병사가 한 명 이상 있어야 전투를 시작한다. 한쪽이라도 비어 있거나, 진형에 병과 수치(§7)에 없는 병과 키가 있으면 전투를 계산하지 않고 "입력 오류"를 돌려준다. 이때는 틱, 해시, 이벤트가 없다. 게임의 배치 화면은 병사를 한 명도 놓지 않으면 전투를 시작할 수 없게 한다.

## §4 한 틱의 처리 순서

전투는 1틱부터 최대 600틱까지 한 틱씩 진행된다. 매 틱마다 아래 ①~⑤를 차례로 처리한다.

**§4.1 단계.**

| 단계 | 하는 일 |
|---|---|
| ① 공격할 병사 모으기 | 진영 0 → 1, 열 0 → 5, 대열 앞 → 뒤 순서로 병사를 하나씩 본다. 대기 시간이 0보다 크면 1 줄인다. 줄인 뒤에도 0보다 크면 이번 틱에는 공격하지 않는다. 대기 시간이 0인데 대열 순번이 사거리 이상이면(사거리 밖) 공격하지 않고, 대기 시간을 0에 둔 채 기다린다(준비된 채 대기). 둘 다 아니면 §4.2로 표적을 고르고, 대기 시간을 간격으로 되돌린다. 이렇게 고른 "누가 누구를 친다"를 의도라고 부른다 |
| ② 공격이 없는 틱 | 이번 틱에 의도가 하나도 없으면 ③~⑤를 건너뛰고 다음 틱으로 간다 |
| ③ 피해 주기 | ①에서 모은 순서대로 피해를 준다. 표적은 ①에서 고른 대로 바꾸지 않는다. 같은 틱에 앞선 공격으로 이미 체력이 0 이하가 된 표적에게도 피해와 기록을 그대로 남긴다. 기록하는 피해는 §4.3 식으로 계산한 값 그대로이고, 표적의 남은 체력보다 커도 줄이지 않는다. 체력과 성문(결계)은 피해만큼 줄고 0 아래로도 내려간다. 0에서 멈추지 않는다 |
| ④ 쓰러진 병사 정리 | 진영 0 → 1, 열 0 → 5, 대열 앞 → 뒤 순서로 본다. 체력이 0 이하인 병사 가운데, 부활 값이 남아 있으면(해골 졸개의 첫 쓰러짐) 체력을 부활 값으로 바꾸고 부활 값을 0으로 한다. 자리는 그대로다. 부활 값이 없으면 대열에서 빼고, 뒤의 병사들이 한 칸씩 앞으로 당겨진다. 당겨진 병사의 대기 시간은 바뀌지 않는다 |
| ⑤ 승패 확인 | §5.1 |

예: 방패병(간격 10)은 1~9틱에는 대기 시간만 10 → 1로 줄고, 10틱에 0이 되어 공격하며 대기 시간이 다시 10이 된다.

예(전진): 사거리 1인 광전사(간격 10)가 방패병 뒤, 대열 1번째에 있다. 10틱에 대기 시간이 0이 되지만 사거리 밖이라 0에 머문 채 기다린다. 37틱 ④에서 방패병이 빠지고 광전사가 맨 앞이 된다. 38틱 ①에서 대기 시간이 0이고 사거리 안이므로 바로 치고, 대기 시간이 10이 된다. 다음 공격은 48틱이다.

예(넘친 피해): 체력이 3 남은 해골 졸개를 같은 틱에 광전사(피해 5)와 방패병(피해 2)이 친다. 기록은 피해 5와 피해 2이고, 졸개의 체력은 3 − 5 − 2 = −4가 된다. ④에서 졸개는 체력 6으로 부활한다.

**§4.2 표적.** "마주 보는 열"은 상대 진영에서 열 번호가 같은 열이다. "왼쪽"은 열 번호가 작은 쪽이다(양쪽 진영 모두 같은 기준).

| 표적 종류 | 고르는 법 |
|---|---|
| 맨 앞 (방패병, 광전사, 해골 졸개, 해골 전사) | 마주 보는 열의 대열 맨 앞. 그 열이 비었으면 상대 성문 |
| 맨 뒤 (척후) | 마주 보는 열의 대열 맨 뒤. 그 열이 비었으면 상대 성문 |
| 지원 (석궁수, 해골 궁수) | 마주 보는 열의 맨 앞. 비었으면 거리 1, 2, 3, 4, 5 순서로 넓혀 가며 찾고, 같은 거리에서는 열 번호가 작은 쪽을 먼저 본다. 처음 찾은 열의 맨 앞을 친다. 모두 비었으면 상대 성문 |
| 범위 (마법사, 해골 술사) | 자기 열 번호를 c라 할 때 c−1, c, c+1 순서로, 진형판 안에 있고 비어 있지 않은 열의 맨 앞을 모두 친다. 진형판 밖의 열(−1번, 6번)은 빈 열로 본다. 세 열이 모두 비었으면 상대 성문을 한 번 친다 |

예(지원): 2열의 석궁수 앞(해골 2열)이 비었으면, 거리 1인 1열과 3열을 보는데 1열을 먼저 본다. 1열에 해골이 있으면 1열의 맨 앞을 친다.

예(범위, 가장자리): 0열의 마법사는 −1열(판 밖), 0열, 1열을 본다. 해골 0열과 1열이 비었으면 −1열도 빈 열이므로 세 열이 모두 빈 것이고, 결계를 한 번 친다.

**§4.3 피해.** 마법은 공격 값 그대로, 물리는 max(1, 공격 − 방어), 성문과 결계는 성문 피해 값(§7, 지금 1)이다. 범위 공격은 표적마다 따로 피해를 준다.

## §5 판정

**§5.1 코어 결과.** ④가 끝난 뒤 진영마다 확인한다. 성문(해골 쪽은 결계)이 0 이하이거나 그 진영의 모든 열이 비었으면 그 진영이 진 것이다.

| 상황 | 결과 |
|---|---|
| 해골(진영 1)만 짐 | A |
| 플레이어(진영 0)만 짐 | B |
| 같은 틱에 둘 다 짐 | Draw(무승부) |
| 600틱까지 아무도 지지 않음 | Timeout(시간 초과). 끝난 틱은 600으로 적는다 |

결과에 적는 성문과 결계 값, 유닛 체력은 음수일 수 있다(§4.1 ③). 화면에는 0으로 보여 줘도 된다. 표시만 바꾸고 결과 값은 바꾸지 않는다.

**§5.2 플레이어 기준 판정.** 위 결과를 화면에 보여 줄 승패와 이름으로 바꾼다.

| 코어 결과 | 판정 |
|---|---|
| A | 승리. 결계가 0 이하면 "결계 파괴", 아니면 "섬멸" |
| Timeout | 승리, "새벽" |
| Draw | 성문이 남아 있으면 승리("성문 사수"), 아니면 패배("성문 붕괴") |
| B | 패배. 성문이 0 이하면 "성문 붕괴", 아니면 "전멸" |

입력 오류(§3.6)는 전투를 계산하지 않았으므로 판정하지 않는다. 승리도 패배도 아니고 판정 이름도 없으며, 게임은 이것을 패배로 세지 않는다.

## §6 이벤트와 해시

전투 중에 일어난 일은 이벤트로 기록한다. 게임 화면은 이 기록을 보고 전투를 재생하고, 테스트는 이 기록으로 만든 해시를 비교한다.

해시는 전투 전체를 숫자 하나로 요약한 지문이다. 이벤트가 하나라도 다르면 해시가 달라지므로, 두 전투가 완전히 같았는지를 숫자 하나로 비교할 수 있다. 계산법은 FNV-1a 32비트다: 시작값 `0x811c9dc5`, 곱하는 수 `0x01000193`. 정수 하나를 섞을 때는 그 정수의 하위 바이트부터 4바이트를 차례로, 해시에 XOR하고 곱수를 곱한다. 곱셈은 32비트를 넘친 부분을 버린다.

| 이벤트 | 종류 값 | 생기는 때 | 로그: 행위자, 표적, 값 | 해시에 섞는 순서 |
|---|---|---|---|---|
| 성문 타격 | 1 | ③에서 표적이 성문(결계)일 때 | 공격자 번호, 999, 피해 | 틱, 1, 공격자 번호, 999, 피해 |
| 피해 | 2 | ③에서 표적이 유닛일 때 | 공격자 번호, 표적 번호, 피해 | 틱, 2, 공격자 번호, 표적 번호, 피해 |
| 부활 | 3 | ④에서 해골 졸개가 일어설 때 | 유닛 번호, 유닛 번호, 부활한 뒤의 체력 | 틱, 3, 유닛 번호 |
| 사망 | 4 | ④에서 대열에서 뺄 때 | 유닛 번호, 유닛 번호, 0 | 틱, 4, 유닛 번호 |
| 종료 | 없음 | 전투가 끝날 때 한 번 | 로그에 넣지 않는다 | 마지막 틱, 결과 코드(A 1, B 2, Draw 3, Timeout 4) |

- 이벤트 기록(로그)의 한 줄은 틱, 종류, 행위자, 표적, 값의 다섯 칸이다. 위 표의 "로그" 칸대로 채운다. 재생 화면은 이 값만 보고 보여 준다.
- 피해의 값은 §4.1 ③대로 계산한 피해 그대로다.
- 종료는 로그와 이벤트 수에 넣지 않고 해시에만 섞는다. 이벤트 수는 종류 1~4인 로그 줄의 개수다.
- 해시에는 표의 마지막 칸에 적은 값만 섞는다. 부활한 뒤의 체력처럼 로그에만 있는 값은 해시에 들어가지 않는다.

## §8 검산 예제

손계산 시나리오(T5)의 출발점이다. 기대값은 AI가 이 문서로 계산하고, 다른 회사 모델이 따로 계산해 비교한다. 다른 곳은 사람이 판정한다(11/20, `Source/RankTests/AGENTS.md`).

1. 광전사와 맞닿은 방패병은 공격 3이다(기본 2 + 링크 1). 해골 전사(방어 1)에게 한 번에 3 − 1 = 2씩 들어가므로 체력 32를 깎는 데 16번이 걸린다. 간격 10틱이니 160번째 틱에 쓰러진다.
2. 석궁수 둘과 맞닿은 방패병은 사거리 3이다(기본 1 + 링크 2). 대열 세 번째 자리(순번 2)에서도 공격한다.
3. 마법사와 맞닿은 척후는 체력 23이다(기본 18 + 5. 11/17 수치 조정 전에는 25). 척후 둘이 마법사 하나를 사이에 끼면, 두 척후가 모두 +5를 받고, 마법사는 간격 −2틱(16 → 14)을 받는다.
