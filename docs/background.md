# RANK & FILE 배경 기획

작성: 2026-11-16. 상태: 초안(검토 중 · AI 제안). 이 저장소로 옮김: 2026-11-17. 결정 근거: `docs/decisions.md` 11/16 "아트 변경"(유닛은 KayKit 3D, 배경은 AI 생성 이미지).

표기: [측정] 이 세션에서 에셋 파일로 계산한 값, [제안] 확정 아님, [미확인] 확인하지 못함, [판단] 근거를 붙인 의견.

## 요약

- 콘셉트: **성 밖 묘지의 달밤.** 해골 군단이 묘지 흙에서 깨어나 성문으로 밀려온다. 기획서의 설정(열두 밤, 성문과 결계, 해골 부활)과 같다.
- 오늘 만들 이미지는 **3장**이다: 아군 쪽 바닥 타일, 적 쪽 바닥 타일, 원경 파노라마.
- 이미지에 **그리지 않는 것**: 성문, 결계, 칸 선, 전선, 팀 표시 고리, 링크. 맞거나 바뀌어야 하는 게임 요소라서 엔진에서 3D와 효과로 만든다.
- 열두 밤의 변화는 **새 이미지 없이** 하늘, 원경, 안개, 결계의 색만 바꿔서 낸다. 바닥 밝기는 거의 그대로 둔다.
- `docs/design.md` 8.6절의 "바닥 1장(4096)"을 "바닥 타일 2장(2048)"으로 바꾼다. 이유는 3.2절.

## 1. 배경이 맞춰야 할 조건

### 1.1 캐릭터 에셋에서 온 조건

KayKit 9종의 GLB에서 몸, 모자, 망토의 삼각형마다 텍스처 색을 읽어 면적으로 가중해 계산했다. 무기와 방패는 뺐다. [측정]

| 유닛 | 평균 명도 | 평균 채도 | 어두운 면(명도 0.35 미만) | 주요 색 |
|---|---|---|---|---|
| 방패병 (Knight) | 0.64 | 0.24 | 5% | 회청색 `#607878`, 피부색, 회색 |
| 광전사 (Barbarian) | 0.57 | 0.28 | 10% | 적갈색 `#604848`, 피부색, 남색 |
| 석궁수 (Rogue) | 0.62 | 0.66 | 5% | 주황 갈색 `#904830`, 녹색 `#006048` |
| 마법사 (Mage) | **0.46** | 0.40 | **37%** | 짙은 남색 `#303048`, 보라 `#484878`, 검정 |
| 척후 (Rogue_Hooded) | 0.57 | **0.82** | 5% | 선명한 녹색 `#007848` |
| 해골 졸개 | **0.77** | 0.36 | 5% | 뼈 베이지 `#d8c0a8` |
| 해골 전사 | 0.57 | 0.24 | 18% | 회색 `#787878`, `#606060` |

| 해골 술사 | 0.56 | 0.49 | 20% | 짙은 자주 `#781830`, `#481830` |

- 해골 4종의 눈은 노랗게 빛나는 재질(Glow, 발광 색 1, 1, 0.19)이다. [측정]
- 크기: 발에서 머리까지 약 2.2, 팔을 벌린 폭 1.94(glTF 단위, 미터로 읽힌다). [측정] 칸 크기는 2.0 [제안], 11/17에 유닛을 세워 확인한다.

여기서 나온 조건

| 조건 | 이유 |
|---|---|
| 바닥 평균 명도 0.28~0.38 | 대부분의 유닛(0.55~0.77)보다 0.15 이상 어둡게 한다 |
| 바닥 평균 채도 0.25 이하 | 척후(0.82), 석궁수(0.66)의 색이 배경보다 먼저 보이게 한다 |
| 바닥 색상은 회청색에서 회녹색 사이 | 아래 '피할 색'을 모두 피하는 범위 [판단] |
| 피할 색: 짙은 남색·보라, 짙은 자주, 밝은 베이지, 선명한 녹색, 주황, 노랑 | 순서대로 마법사, 해골 천, 해골 뼈, 척후, 석궁수·광전사, 해골 눈과 겹친다 |

[판단] 마법사(어두운 면 37%)와 해골 궁수·술사의 짙은 천은 어떤 바닥에서도 묻힐 수 있다. 이것은 배경으로 해결하지 않는다. 게임이 그리는 팀 고리(2.3절)와 달빛 역광으로 윤곽을 살린다.

### 1.2 게임 규칙에서 온 조건

| 규칙 | 배경에 주는 조건 |
|---|---|
| 위에 해골 진형 6×4, 가운데 전선, 아래에 아군 진형 6×4 (기획서 참조 시뮬레이터) | 화면을 위아래로 나눈다. 위는 적의 땅, 아래는 우리 땅 |
| 성문(아래)과 결계(위)는 체력 60이고 맞으면 줄어든다 (기획서 §2.7) | 그림으로 그리면 반응할 수 없다. 3D 소품과 효과로 만든다 |
| 해골은 땅에서 깨어나고 졸개는 한 번 부활한다 (`Spawn_Ground_Skeletons`, `Death_C_Skeletons_Resurrect`) | 적 쪽 바닥이 묘지 흙이면 동작과 설정이 맞는다 |
| 전투는 열(file) 단위로 진행된다 (기획서 §2.3) | 바닥에 강한 대각선이나 큰 무늬를 넣지 않는다. 열이 흐려진다 |

### 1.3 화면 단계에서 온 조건

레벨은 전장 하나(`L_Field`)이고 모든 화면을 그 위에 띄운다(`docs/design.md` 8.4절 [제안]).

| 화면 | 카메라 [제안] | 배경에서 보이는 것 | 필요한 에셋 |
|---|---|---|---|
| 메인 메뉴 | 전장을 넓게 비스듬히 | 전장 전체와 원경 | 새로 만들지 않음 |
| 보상 | 전투 카메라 그대로, 화면을 흐리고 어둡게 | 흐린 전장 | 없음 |
| 배치 | 거의 수직으로 내려다봄 | **바닥만** 보인다. 칸 읽기가 가장 중요 | 바닥 타일 2장 |
| 전투 | 비스듬히 내려다봄(약 50~60도) | 바닥, 결계, 화면 위쪽 띠에 원경 | 바닥 타일 2장, 원경 |
| 결과 | 전투 마지막 장면 정지 | 전투와 같음 | 없음 |
| 런 종료 | 메인 메뉴와 같음 | | 없음 |
| 영상 타이틀, 스크린샷 | 전투 화면 캡처 | | 없음 |

배치 화면과 전투 화면 두 곳에서 바닥이 가장 오래, 가장 크게 보인다. 오늘 만들 이미지의 우선순위도 바닥이 먼저다.

## 2. 콘셉트: 성 밖 묘지의 달밤

### 2.1 화면 구성 (전투 카메라, 위에서 아래로)

```
┌──────────────────────────────────────────┐
│ 원경 파노라마: 밤하늘과 달, 소나무 숲 실루엣, │  BG-03 (AI 이미지)
│ 무너진 묘지 담과 작은 납골당                 │
├──────────────────────────────────────────┤
│ 결계: 보랏빛 빛의 띠, 체력에 따라 옅어짐      │  효과 (엔진)
├──────────────────────────────────────────┤
│ 해골 진형 6×4: 묘지 흙 바닥                  │  BG-02 (AI 타일)
├──────────────────────────────────────────┤
│ 전선: 두 바닥이 섞이는 띠                    │  재질에서 섞음
├──────────────────────────────────────────┤
│ 아군 진형 6×4: 닳은 돌바닥                   │  BG-01 (AI 타일)
├──────────────────────────────────────────┤
│ 성문: 아치 문, 울타리, 등불                  │  KayKit 3D 소품
└──────────────────────────────────────────┘
```

### 2.2 이 콘셉트를 고른 이유 [판단]

1. 기획서의 설정과 같다: 해골 군단이 몰려오는 열두 밤, 성문을 지킨다.
2. 에셋과 맞는다: 해골이 땅에서 깨어나는 애니메이션이 있고, 해골 눈이 빛나서 밤에 잘 보인다.
3. 흔한 자동 전투 게임의 낮 들판 배경과 겉모습이 달라진다.

### 2.3 색의 역할

화면에서 색마다 하나의 뜻만 갖게 한다. 배경 이미지에는 아래 색을 쓰지 않는다. [제안]

| 색 | 뜻 | 그리는 곳 |
|---|---|---|
| 청록 | 아군 | 아군 유닛 발밑 고리 |
| 붉은색 | 적 | 해골 발밑 고리, 정예 밤의 하늘 |
| 금색 | 링크 | 맞닿은 변의 표시(기획서 시안 1) |
| 보라 | 결계 | 결계 띠 |
| 따뜻한 주황 | 성문, 등불 | 성문 쪽 등불 빛 |
| 노랑 | 해골 눈 | 에셋 그대로 |

### 2.4 조명 [제안]

| 빛 | 설정 | 하는 일 |
|---|---|---|
| 달빛 | 차가운 흰빛의 방향광 1개, 그림자 생성. 화면 안쪽(적 쪽)에서 비스듬히 | 유닛 윤곽에 역광이 생겨 어두운 유닛이 살아난다 |
| 성문 등불 | 따뜻한 점광 2~4개, KayKit `lantern_standing`, `post_lantern` | 아군 쪽을 따뜻하게, 적 쪽과 구분 |
| 결계 | 보라 발광 | 적 쪽 끝을 표시 |

- Lumen, Nanite, 가상 그림자는 쓰지 않는다. 5.8 기준으로 Lumen은 RTX 2000 이상, Nanite와 가상 그림자는 SM6.6이 필요해서([Epic: 하드웨어 사양 5.8](https://dev.epicgames.com/documentation/unreal-engine/hardware-and-software-specifications-for-unreal-engine?application_version=5.8)) 에디터가 없는 다른 PC나 시연용 노트북에서 문제가 될 수 있다. 로우폴리 게임에는 필요 없다. [판단]
- 노출은 수동(Manual)으로 고정한다. 수동 모드는 장면 밝기와 상관없이 한 값으로 고정된다([Epic: Auto Exposure](https://dev.epicgames.com/documentation/en-us/unreal-engine/auto-exposure-in-unreal-engine)). 자동 노출을 켜 두면 밤마다 어둡게 맞춘 화면을 엔진이 다시 밝힌다.

### 2.5 열두 밤의 변화 [제안, 선택 작업]

| 밤 | 분위기 | 바꾸는 값 |
|---|---|---|
| 1~3 | 초저녁. 가장 밝다 | 하늘 보랏빛, 안개 없음. 첫 밤 튜토리얼이 있어 가독성을 우선한다 |
| 4 (정예) | 붉은 기운 | 하늘과 결계에 붉은색, 안개 조금 |
| 5~7 | 한밤 | 하늘 짙은 파랑 |
| 8 (정예) | 붉은 기운, 4보다 짙게 | 4와 같고 값만 더 |
| 9~11 | 깊은 밤 | 하늘 더 어둡게, 안개 조금 |
| 12 (우두머리) | 붉은 달 | 원경 재질의 달 색만 바꾼다 |

- 값은 머티리얼 파라미터 컬렉션(Material Parameter Collection) 하나에 모아, 여러 재질이 같은 값을 읽게 한다. 실행 중에 값을 바꿀 수 있다. 이 프로젝트는 로직을 C++에만 두므로(11/17) 값을 바꾸는 일은 C++에서 한다([Epic: Material Parameter Collections](https://dev.epicgames.com/documentation/en-us/unreal-engine/using-material-parameter-collections-in-unreal-engine)).
- 바닥의 밝기는 바꾸지 않는다. 유닛 가독성이 밤마다 달라지면 안 된다.
- 밀리면 버린다. 일정표의 버리는 순서 4번(`docs/design.md` 13.4) "정예·우두머리 전용 연출"에 함께 넣는다.

### 3.2 바닥을 한 장이 아니라 타일 2장으로 하는 이유 [판단]

1. AI 이미지 생성은 한 장 안의 정해진 위치에 구역(아군 땅, 전선, 적 땅)을 정확히 그리기 어렵다. 타일 2장이면 구역의 위치는 엔진에서 정확히 정한다.
2. 타일 1장이 칸 2×2(4m)마다 반복되게 깔면, 무늬의 주기가 칸과 맞아 칸 선과 어긋나 보이지 않는다.
3. 해상도가 높아진다. 4096 한 장으로 전장 전체(약 30m)를 덮으면 1m에 약 136픽셀이지만, 2048 타일을 4m마다 반복하면 1m에 512픽셀이다.
4. 3장 모두 크기가 2의 거듭제곱이다. 2의 거듭제곱 크기여야 텍스처 스트리밍이 된다([Epic: Textures](https://dev.epicgames.com/documentation/unreal-engine/textures-in-unreal-engine?lang=en-US)).

### 3.3 바닥 배치 (칸 2.0 기준) [제안]

| 구역 | 크기(가로 × 세로) | 바닥 |
|---|---|---|
| 결계 앞 | 12m × 2m | BG-02 |
| 해골 진형 | 12m × 8m | BG-02 |
| 전선 | 12m × 2m | BG-01과 BG-02를 섞음 |
| 아군 진형 | 12m × 8m | BG-01 |
| 성문 앞 | 12m × 2m | BG-01 |
| 좌우 여백 | 각 6m 이상 | 같은 타일을 더 어둡게. 화면 끝까지 채운다 |

## 4. 생성 사양과 프롬프트

### 4.1 공통 조건

- 화풍은 KayKit에 맞춘다: 로우폴리, 면이 단순한 색, 사실적인 질감 없음. 도구가 참고 이미지를 받으면 KayKit 미리보기(각 KayKit 저장소의 Halloween Bits, Dungeon 미리보기)를 화풍 참고로 넣는다. KayKit은 CC0다.
- 프롬프트에 기존 게임, 회사, 작가의 이름을 넣지 않는다. 타인 저작물을 넣지 않는다.
- 이음새 없는 타일 옵션이 있는지는 도구마다 다르다. [미확인] 없으면 이미지를 가로세로 반씩 밀어(offset) 이음새를 가운데로 모은 뒤 지워서 고친다.
- 장마다 후보 3~4개를 만들고 5절 기준으로 1개를 고른다.

### 4.2 BG-01 아군 쪽 바닥

조건: 바로 위에서 본 그림(원근 없음), 높이 있는 물체 없음, 그림자 없음, 칸 선 없음, 회청색, 명도 0.28~0.38.

```
Seamless tileable texture, top-down orthographic view, no perspective.
Worn flat stone paving with thin dark gaps, small dirt patches and a little moss.
Stylized low-poly game art, flat shaded, simple colors, no photorealism.
Cool desaturated blue-grey palette, medium-dark value, low contrast.
Even lighting, no cast shadows, no objects with height, no grid lines, no text.
```

### 4.3 BG-02 적 쪽 바닥

조건: BG-01과 같은 조건에 색은 회녹색에서 회갈색, BG-01보다 조금 어둡게. 뼈와 해골은 넣지 않는다(해골 졸개의 뼈 색과 헷갈린다).

```
Seamless tileable texture, top-down orthographic view, no perspective.
Graveyard soil: dark packed earth with a few small flat stones, faint cracks and sparse dry grass.
Stylized low-poly game art, flat shaded, simple colors, no photorealism.
Desaturated grey-green to grey-brown palette, medium-dark value, low contrast.
Even lighting, no cast shadows, no bones, no skulls, no gravestones, no text.
```

### 4.4 BG-03 원경 파노라마

조건: 4:1 가로 그림, 사람과 글자 없음, 아래쪽 4분의 1이 어두운 땅색으로 흐려짐, 노랑·주황·보라 강조 없음(해골 눈, 등불, 결계와 겹친다).

```
Wide panoramic game background, 4:1 aspect ratio, side view at ground level, night.
Silhouettes of a dark pine forest and a crumbling graveyard wall with a small crypt,
under a deep blue night sky with a large pale moon and thin clouds.
Stylized low-poly game art, flat simple colors, soft gradients, no photorealism.
Low contrast and desaturated; the bottom quarter fades into dark grey-green ground.
No characters, no text, no bright lights, no orange, yellow or purple accents.
```

## 5. 고르는 기준

하나라도 어기면 다시 만든다.

| # | 기준 | 확인 방법 |
|---|---|---|
| 1 | 바닥 평균 명도 0.28~0.38, 평균 채도 0.25 이하 | 코드로 잰다 |
| 2 | BG-02가 BG-01보다 조금 어둡다(명도 차 0.03~0.08) | 코드로 잰다 |
| 3 | 원근, 높이 있는 물체, 그림자, 칸 선이 없다 | 눈으로 본다 |
| 4 | 2×2로 이어 붙였을 때 경계가 보이지 않는다 | 이어 붙인 이미지를 본다 |
| 5 | 강한 대각선이나 큰 무늬가 없다 | 눈으로 본다 |
| 6 | KayKit 9종을 진형판 크기로 올렸을 때 묻히는 유닛이 없다(고리 없이 봐서 마법사, 해골 궁수·술사 제외) | 합성 미리보기 |
| 7 | 원경 아래쪽 색이 BG-02와 이어지고, 노랑·주황·보라 강조가 없다 | 눈으로 본다 |
| 8 | 글자, 워터마크, 기존 게임을 닮은 요소가 없다 | 눈으로 본다 |

후보 파일을 주면 1, 2, 4번은 코드로 검사하고, 6번용 합성 미리보기를 만들어 줄 수 있다.

## 6. 엔진에 넣는 방법 [제안]

| 대상 | 방법 |
|---|---|
| 바닥 | 평면 위에 재질 하나. BG-01과 BG-02를 위치(앞뒤 좌표)에 따라 섞고, 전선 2m 구간에서 부드럽게 바꾼다. 타일 반복은 4m마다 |
| 원경 | 결계 뒤에 세운 판. 조명 영향을 받지 않는 재질(Unlit). 색 곱하기 값을 머티리얼 파라미터 컬렉션에서 읽는다 |
| 텍스처 | `Content/Environment/BG/T_BG_GroundAlly`, `T_BG_GroundEnemy`, `T_BG_Backdrop` |
| 칸 선, 전선 | 바닥 위에 그리는 데칼이나 얇은 메시. 배치 화면에서만 진하게 |
| 팀 고리 | 유닛 발밑 데칼. 아군 청록, 적 붉은색 |
| 결계 | 보라 발광 띠. 체력 비율로 투명도를 바꾼다 |
| 성문 | KayKit `arch_gate`, `fence`, `fence_pillar`. 맞을 때 흔들림과 번쩍임 |

## 8. 기록과 공개

## 9. 되돌릴 길

1시간 안에 5절 기준을 채우지 못하면:
- BG-01·02 대신 KayKit 바닥 조각(`floor_dirt`, `floor_dirt_grave`, `path_A`~`D`, Dungeon의 `floor_tile_*`)을 깐다.
- BG-03 대신 단색 그라데이션 하늘에 KayKit 소나무와 마른 나무를 실루엣으로 세운다.
